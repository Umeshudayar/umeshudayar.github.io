## Publish with GitHub Pages
1. Create a public repository named `umeshudayar.github.io` under the GitHub account `Umeshudayar` (if available).
2. Upload `index.html`, `resume.pdf`, and the `assets` folder to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for the Pages deployment and open `https://umeshudayar.github.io/`.

GitHub Pages serves static files. Do not upload passwords, API keys, or private documents.
